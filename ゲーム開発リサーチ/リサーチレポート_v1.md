## 各ゲームの設計課題

### クイズ航海
- **問題数24問のみ** → 5回プレイすれば大半暗記
- **固定誤答選択肢** → 正答を選択肢の並びで推測できる
- **15/24問ランダム選択** なので2〜3回で全問正解化

### 砲撃戦
- **失敗ペナルティゼロ** → 外しても何のリスクもない
- **敵船3種のみ** → 60秒で変化に乏しい
- **難易度設定なし** → 初心者とベテランが同じ体験
- **ベスト1件保存** → 成長記録が1つしか残らない

### 宝の地図
- **kraken（dmg=9）が実質即死** → Hard HP=2で1発ゲームオーバー、バランス崩壊
- **フラグ機能が形だけ** → 立てても攻略に役立たない
- **Easyにダイヤ・トライデント未登場** → 報酬の段階感なし

### 大海の覇者
- **スピードが死にステータス** → 帆アップグレードの価値が一斉砲撃解放のみ
- **イベント8種のみ** → 10戦するとパターンが読めてくる
- **BOSSバーサーク発動が理不尽** → 1ターン前に「発動」テキストが出るが次ターン即高火力

## Anthropic API 活用案

### A案 — クイズ動的生成（最高インパクト）
固定24問から**無限生成**へ。ワールドカップ2026参加国テーマで毎回新鮮な問題を生成。

```
モデル: claude-haiku-4-5 （安価・高速）
コスト目安: 1問生成 ≈ 入力150tok + 出力150tok ≈ 約$0.0003/問
```

実装イメージ:
- APIキーをlocalStorageに保存（ユーザーが入力）
- 15島のうちAIモードON時は全問AIが生成
- 応答はJSON強制（`{"name":"国名","hints":[3個],"choices":[4択]}`）
- 失敗時は静的問題にフォールバック

### B案 — 大海の覇者 AIイベント生成（体験の多様化）
固定8種イベントをAIが毎回ユニークな海賊話として描写。

```
モデル: claude-haiku-4-5
コスト: 1イベント ≈ $0.0002
```

例：「難破船を発見した」→ AIが毎回違うフレーバーテキスト生成
`"嵐で帆柱が折れた難破船から商品を回収。積荷の中に古地図が..."` など

### C案 — 海賊船シミュレーター AIナレーション（演出強化）
大きな撃破・連続撃破時にAIが一言実況を生成（20字程度）。
